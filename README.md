# AI CAR WITH REAL-TIME DETECTION OF DAMAGED ROAD AND LANE DETECTION

AI Car with Real-Time Detection of Damaged Road and Lane Detection is an intelligent AI-powered transportation system designed to improve road safety by detecting road damages such as potholes and cracks while simultaneously identifying lane markings in real time. The system processes live video streams, uploaded videos, and images using Deep Learning and Computer Vision techniques to assist drivers, Advanced Driver Assistance Systems (ADAS), and autonomous vehicles in navigating safely. By integrating YOLOv8 object detection, OpenCV-based lane detection, GPS location tracking, and a Flask web application, the system provides accurate road condition analysis, real-time hazard detection, and location-based reporting for efficient road maintenance. Built using Python, Flask, SQLite, OpenCV, and YOLOv8, the application combines Artificial Intelligence, Deep Learning, and Computer Vision to deliver a fast, reliable, and intelligent road safety solution.

### Overview:

• Users can securely log in and access the intelligent road monitoring dashboard.

• The application allows users to upload images or videos for automatic road damage and lane detection.

• A YOLOv8 Deep Learning model accurately detects potholes, cracks, and other road damages in real time.

• The system performs lane detection using Computer Vision techniques to identify lane boundaries and assist safe vehicle navigation.

• GPS coordinates are captured during detection and stored in a SQLite database for location-based road damage reporting.

• The application displays real-time detection results with bounding boxes, FPS, accuracy, collision status, and damage count through an interactive web interface.

Built using Python, Flask, SQLite, OpenCV, Ultralytics YOLOv8, HTML, CSS, JavaScript, and Computer Vision techniques, the project demonstrates how Artificial Intelligence and Deep Learning can be integrated into intelligent transportation systems to improve road safety, support autonomous driving, and enable efficient road maintenance.


## Tech Stack:

• Python – Core programming language for backend development

• Flask – Web framework for application development and routing

• SQLite – Lightweight relational database for storing GPS coordinates, detection history, and user information

• OpenCV – Image processing, video processing, lane detection, and Computer Vision operations

• Ultralytics YOLOv8 – Deep Learning model for real-time road damage and lane detection

• NumPy – Numerical computing and image array processing

• HTML – Structure of the web application

• CSS – Responsive and modern user interface styling

• JavaScript – Interactive frontend functionality and GPS location capture

• Flask-CORS – Cross-Origin Resource Sharing support

## Features:

🚗 Real-Time Road Damage Detection — Detects potholes, cracks, and damaged road surfaces using YOLOv8.

🛣️ Lane Detection — Identifies lane markings for safer vehicle navigation using Computer Vision.

📹 Live Video Processing — Supports real-time detection on uploaded videos.

🖼️ Image Detection — Performs accurate detection on uploaded road images.

📍 GPS Location Tracking — Captures latitude and longitude of detected road damages.

🗺️ Road Damage Mapping — Stores GPS coordinates in SQLite for future road maintenance and visualization.

⚡ Real-Time Performance Monitoring — Displays FPS, inference time, preprocessing time, postprocessing time, and detection accuracy.

🚨 Collision Warning — Indicates SAFE or DANGER status based on detected road hazards.

👤 User Authentication — Secure login, signup, session management, and personalized dashboard.

💾 Database Integration — Stores user details, GPS locations, and road damage detection history using SQLite.

🌐 Responsive Web Application — Modern, clean, and user-friendly interface accessible from multiple devices.
